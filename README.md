# Benchmarking Dashboard (비즈니스 컨설팅 리포트)

URL 도메인 기반 실측 기업정보 분석, IR 인텔리전스, 트래픽 및 버닝레이트 분석을 제공하는 B2B 비즈니스 컨설팅 대시보드 플랫폼입니다.

---

## 🚀 서비스 오픈 기준 데이터 정합성 원칙 (Data Consistency Manifesto)

본 서비스는 사용자가 어떤 URL 도메인을 검색하더라도 **오직 외부 공시 및 실측으로 검증된 실제 데이터의 숫자만 노출**하며, 가상 추정 정보 생성을 원천 차단합니다.

### 1. 절대 원칙: 가상 및 추론 정보 생성 금지 (Zero Hallucination)
- 원본 공시(DART 전자공시, 사람인, 국민연금 사업장 공시, NICE평가정보, 중소벤처기업부 공공데이터 등)에 존재하지 않는 정보나 수치는 절대로 임의로 생성하거나 유추하여 채워 넣지 않습니다.
- 데이터 원본 간 값이 매칭되지 않거나 빈 값(Null)일 경우, `[미확인: 정보 없음]` 또는 공란 배너로 투명하게 처리합니다.

### 2. 근로 인원수(임직원 수) 실측치 100% 동기화
- **공시 기준**: 중소벤처기업부 공공데이터 · NICE평가정보 & 사람인 (주)아이오로라 공시
- **연도별 실측 인원수**:
  - **2026년 (9월 최신)**: **45명** (기존 가상 추정치 54명 폐기)
  - **2025년 말**: **41명** (기존 가상 추정치 47명 폐기)
  - **2024년 말**: **27명** (기존 오류치 47명/34명 폐기)
  - **2023년 말**: **28명**
  - **2022년 말**: **28명**
- 재무 히스토리(`financialHistory`), 투자 유치 이력(`investments`), 데이터 소스 카탈로그(`dataSourcesCatalog`) 및 IR 상세 뷰(`IrDetailSubpage`) 전반에 100% 일치 적용되었습니다.

### 3. 도메인 간 데이터 교차 오염 방지
- 도메인 검색 시 타사 데이터(나마네카드, 동거동락 등)의 제휴 파트너나 전략이 강제 fallback되어 섞이지 않도록 엄격한 도메인 격리 파이프라인이 적용되어 있습니다.
- 모바일 앱이 없거나 확인되지 않는 웹 서비스(예: `medi114.co.kr` 등)는 임의의 앱 지표를 표시하지 않고 입력된 웹 도메인의 트래픽 데이터만 정확히 표시합니다.

## 🛠️ 주요 기능 및 메뉴 구성

1. **GNB 메뉴**:
   - `서비스 소개` | `이용방법` | `제품` | `데이터 출처`
2. **비즈니스 컨설팅 리포트 & 제품 체험**:
   - URL 입력창을 통한 원클릭 기업 인텔리전스 도출
   - 트래픽(현) 실측 지표 분석
   - 연간 버닝레이트 분석 (인건비, 인프라비, 세금, 임대료, 서버비 5대 지출 분해)
   - 투자 유치 이력 및 주주 구성 (공시 100% 일치)
   - DART 전자공시 vs 혁신의숲 2대 공시 교차 검증
